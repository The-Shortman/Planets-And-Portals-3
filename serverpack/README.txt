This modpack uses Forge Server Starter by HellBz to automatically do most of the server setup.

Quickstart guide:
1. Install this server pack on the server you are using.
2. Start the server pack with the included "server.bat" batch file.
   - On Windows, just double click the file and it should run.
   - On machines with BASH capabilities (e.g. Linux), open your terminal in the server directory and enter "bash server.bat".
3. The batch file will automatically install Forge and boot up the world.

Configuration:
- server.properties
  - Some values in server.properties have been customised for this modpack. Feel free to adjust based on your needs.
- server.bat
  - You can edit the -Xmx flag to set the server's maximum RAM allocation.
- forge-auto-install.txt
  - Do not edit this file. Defines the versions of Minecraft, Forge, and Forge version to use.
- server_starter.conf
  - This file allows you to configure some more technical settings.
  - If you wish to set your server's timezone you may do so in this file.
  - If you have a custom directory for your Java installation, you can define it here.
